# 环境变量与启动

变量清单见 [`docs/environments.md`](../../../docs/environments.md)。本文是实现约束。

## 1. 启动时一次性校验

进程启动的**第一件事**是校验全部环境变量。缺一个就拒绝启动，并打印**缺了哪个**。

```ts
// ✗ 把问题推到第一次调用时
const key = process.env.CONFIG_ENC_KEY!

// ✓ 启动即失败，错误现场就是根因
const env = parseEnv(process.env)   // 失败则 process.exit(1)
```

`process.env.X!` 的问题不是类型不安全，是**报错时机**：第一次调用可能发生在部署后几小时的某次导入里，那时的堆栈离「忘了配环境变量」已经很远了。

除了这个经过校验的 `env` 对象，**代码里不应该再出现 `process.env`**。

## 2. 额外校验

| 变量 | 额外检查 |
|---|---|
| `CONFIG_ENC_KEY` | **必须是 32 字节**，短了直接拒启动 |
| `DATABASE_URL` | 能解析成合法连接串 |
| `R2_KEY_PREFIX` | 以 `/` 结尾（不带会导致对象键拼错） |
| `R2_PUBLIC_BASE_URL` | **不**以 `/` 结尾（带了会拼出 `//`；键本身不带前导 `/`） |
| `R2_ENDPOINT` | 可选。设了就是 S3 兼容实现（RustFS / MinIO），必须带 `http://` 或 `https://`；此时 `R2_ACCOUNT_ID` 可不填 |
| `R2_PUBLIC_ENDPOINT` | 可选。浏览器直传用的 endpoint，必须带协议头；容器内地址与宿主可达地址不同时必须分开配 |
| `R2_FORCE_PATH_STYLE` | 可选。显式 `true` 才开；非 AWS 实现通常必须，正式 R2 不能开 |
| `DEFAULT_VISION_*` / `DEFAULT_EMBED_*` | **可以全空**，见 §4 |

`CONFIG_ENC_KEY` 长度不对时 AES-GCM 会在第一次加密用户 key 时才报错——那时用户正在设置页点保存，看到的是一个莫名其妙的 500。

## 3. 启动顺序

```
1. 校验 env          → 失败则 exit(1)
2. 探活 R2           → 失败则 exit(1)
3. 连数据库          → 失败则重试几次后 exit(1)
4. 检查迁移版本      → 落后则打印提示并 exit(1)
5. 起 HTTP + worker
```

第 2 步和第 1 步是同一件事的两半：**「变量填了」和「填的能用」**。

R2 是本项目唯一一个「配错了在运行期也完全不报错」的依赖——预签名是纯本地 HMAC 计算，假凭证照样签得出格式完美的 URL，`POST /imports` 返回 200，错误最终只在浏览器里以一句 TLS 握手失败现身（2026-09-18 实际发生过）。所以它必须在启动时探一次，`ListObjectsV2` + `MaxKeys: 1` 即可。

三个约束：**`NODE_ENV=test` 跳过**（否则单测全变成要联网）、**必须带超时**（网络不通时要起不来，不能吊死在启动上）、**错误信息只带 endpoint / bucket / 前缀，绝不带凭证**（硬边界，SPEC §5.3；S3 的鉴权错误体会回显 AccessKeyId，所以只取 `error.name`）。

这**不是**按环境分支：除 `test` 外所有环境行为一致。本地开发也要能连上 R2，理由见 [`docs/environments.md`](../../../docs/environments.md) §4——上传路径不做「本地存文件系统」的分支。

第 4 步**只检查，不自动执行迁移**。理由见 [`docs/deployment.md`](../../../docs/deployment.md)：多副本时会并发迁移，而那种故障发生在启动瞬间，最难排查。

## 4. 默认模型配置可以全空

`DEFAULT_VISION_*` 和 `DEFAULT_EMBED_*` 全空时**照常启动**。

这不是容错，是[产品要求的行为](../../../docs/product.md)：

- 没有默认视觉配置 → 导入仍然允许，图片入库为 `tagStatus = pending`
- 没有默认 embedding 配置 → 搜索降级为 OCR + 标签，`degraded: true`

**不能因为没配模型就拒绝启动或拒绝上传。** 启动时打一条 warn 说明当前处于哪种降级态就够了。

## 5. 本地与生产的唯一分支

会话 cookie 的 `Secure` 标志：本地不设，生产必须设。

**这是允许按环境分支的唯一一处配置。** 其他任何「本地走这条路、生产走那条路」的写法都要先问清楚为什么——尤其是上传路径，[不要做「本地存文件系统」的分支](../../../docs/environments.md)。

## 6. 不要把配置藏进代码

RRF 的 `k`、Hamming 阈值、抽帧数、超时时长这些**写成有名字的常量**，集中在一处，不散落成魔数。

但**不要把它们做成环境变量**——它们是需要跟着[评测集](../../../docs/eval.md)一起调的参数，做成环境变量意味着生产和评测环境可能跑着不同的值，评测结果就失去意义了。
